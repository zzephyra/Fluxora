# ADR-017: 三入口项目工作区

## Status

Accepted — 2026-09-27，依据用户明确要求调整工作区为创作、资产和生成三项导航。

## Decision

保留项目鉴权与 project_id 边界，替换 ProjectEntryPage 成功状态下的未开放占位页，嵌入项目工作区。导航匹配真实 URL，三个页面可直接访问。复用既有 Button、Input、Dialog、AccountMenu；不新增运行时依赖。

工作区采用图形 Logo，预设问题集中为类型化配置，点击只填充草稿。图片/视频模式提供 UI 准备入口，不伪造未接入的模型能力、业务结果或真实资产。业务 API 未实现时禁用对应提交并说明原因。当前图像生成属于用户授权的 UI 扩展；接入真实图片模型前必须扩展服务端 capability 与测试，不能把 text_to_video 当成图片模型。

## Consequences

三个入口优先，原文档中知识库、记忆、设置等路由不自动加入侧栏。后续按已确认范围补充，不隐藏实现范围差异。项目组件按 project_id 挂载，避免临时草稿串项目；完整约束见前端规范第 8 节。

## Validation

验证预设填充、当前路由高亮、模式切换、清空确认、项目状态重置，以及原登录/项目授权测试。尚未接入的业务不能以 UI 测试通过宣称已实现。
