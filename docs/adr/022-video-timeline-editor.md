# ADR-022: 项目内视频时间线编辑器

## Status

Accepted — 2026-09-28。用户明确回复“允许”，批准本决定的范围、依赖及实现。

## Context

ARCHITECTURE.md 第 1 节明确排除首期时间线剪辑，第 3 节暂不引入 Zustand。当前 React / TypeScript SPA 已有 React Router、TanStack Query、Radix UI 和图片编辑器；视频结果仅通过受授权的资产接口播放。现有异步生成任务限定 image / video 生成，不能把本地剪辑渲染伪装成供应商生成。

## Decision

将单视频轨道非破坏性剪辑纳入当前实现范围。允许引入 Remotion、匹配版本的 Remotion Player、Zustand 和 dnd-kit；现有组件继续负责按钮、弹窗与菜单。Remotion 负责逐帧预览，Zustand 仅保存当前编辑会话的本地文档、播放、UI 和撤销历史，服务端状态仍使用 TanStack Query。现有 Konva 图片编辑器不承担视频时间线。

### 集成与文档

- 从已成功生成的视频结果进入 `/projects/:projectId/editor/:documentId`，返回生成页；不建立独立 Demo。
- 后端 editor 模块管理编辑文档及渲染任务，复用认证、成员检查、UoW、对象存储与任务运行基础设施，不直接读写其他模块业务表。需要资产信息时扩展既有资产访问用例。
- 编辑文档在 PostgreSQL 保存 schema_version、project_id、fps、width、height、durationInFrames、tracks、revision；资产字节保留在私有对象存储。保存采用 revision 并发检查，冲突返回 409。
- clips 只持久化授权 asset_id，不存短期 URL。浏览器按资产接口解析播放地址；导出的 Project JSON 同样使用资产引用。
- 时间统一为整数帧，区间左闭右开，第一版固定工程 30fps、speed=1，不暴露未实现的变速按钮。源媒体通过实际元数据建立帧边界，不把任意视频时长硬编码成 5 秒。
- 第一版仅允许一条视频轨道、无重叠片段；拖动和裁剪不能跨越相邻片段。删除保留时间空隙，预览及最终渲染中空隙表现为黑画面与静音。保留源音频，支持静音和音量。

### 编辑与性能

- 实现连续缩略图、帧级定位、播放双向同步、裁剪、分割、删除、移动、吸附、缩放、快捷键、添加同空间已有视频、撤销和重做。
- 每次拖动只产生一条撤销记录；播放头、播放状态、选中、缩放不进入文档历史。播放更新使用 store selector 隔离，不使整个编辑器逐帧重渲染。
- 缩略图服务优先复用授权媒体接口，以浏览器 video + canvas 抽取可视区域所需帧；按媒体地址和时间缓存，限并发、限缓存大小，并在卸载时释放资源。不逐帧抽取，不一次渲染全部缩略图。
- 公共 frame/pixel/time 转换、编辑纯函数、历史、快捷键和播放同步分别拆分；表单聚焦时不拦截 Delete、Space 等输入按键。

### 保存与导出

- “保存”真实保存工程到 PostgreSQL；“导出工程”下载版本化 JSON；“导出视频”创建异步渲染任务，不能把 JSON 下载称作视频导出完成。
- 视频导出使用服务端 FFmpeg，原始素材不改写；不引入浏览器 ffmpeg.wasm。渲染任务单独持久化，使用 queued/running/succeeded/failed/canceled 状态，幂等键按 project_id、actor_id 限定，任务保存不可变工程快照。
- Worker 从受控资产读取输入，执行时重新验证访问权限；不接受任意 URL、文件路径或 FFmpeg 命令。通过参数数组调用 FFmpeg，设置媒体大小、总帧数、任务超时及并发上限，清理临时文件，记录可恢复失败。
- 统一帧率、尺寸、裁剪区间、静音、音量和空隙语义；输出视频写入现有私有资产体系，成功后经授权接口预览与下载。
- Remotion 预览和 FFmpeg 导出共享受限工程契约；后续字幕、转场、图片或特效必须同时定义两侧语义，不能只加预览效果。

## Validation

每阶段完成类型检查和相关测试。补充帧转换、裁剪边界、分割连续性、非重叠移动、吸附、历史合并、快捷键与输入框隔离测试。后端覆盖成员隔离、资产归属、保存冲突、导出幂等与失权处理。以真实视频验证缩略图、播放同步，以及带空隙的最终导出文件与源区间一致。检查现有生成流程未回归。没有配置真实运行依赖时不能声称导出验收完成。

## Consequences

增加编辑文档与渲染任务迁移、FFmpeg 运行依赖和 Remotion 等前端依赖。接受后同步总架构、前端/API/数据/运行规范与依赖锁文件。字幕、音轨编辑、转场、贴纸与 AI 特效仅保留扩展边界，不展示不能工作的按钮。
