# ADR-025: 资产与视频导出运营后台

## Status

Accepted — 2026-09-29。用户明确确认新增管理权限范围并授权实现。

## Context

ADR-024 只批准用户管理与生成任务运营元数据，明确禁止后台访问私有素材和成片内容。资产归属分为用户级 upload_files（七牛直传）与项目级 assets（生成和编辑导出）；不能用项目 ID 冒充上传素材归属。editor_renders 具有 queued/running/succeeded/failed/canceled 状态，现有 Worker 用行锁领取 queued，但没有管理取消接口。

## Decision

### 资产管理 /admin/assets

- 扩展 platform_admin，仅允许全平台资产运营元数据查询。采用“用户上传”和“项目资产”两个标签，各自服务端分页，不把两类归属伪装成同一个项目模型。
- 上传标签支持按文件 ID、用户 ID、类型、状态、创建时间筛选；展示文件 ID、用户 ID、类型、MIME、字节大小、状态、创建时间。不返回原始文件名、URL、bucket、object_key、上传凭证或文件内容。
- 项目资产标签支持按资产 ID、项目 ID、创建者 ID、类型、状态、创建时间筛选；展示归属、大小、分辨率、状态及来源（AI 生成、编辑器导出或其他）。来源查询通过各所属模块 Service，禁止跨模块直接查询表。
- 展示当前筛选范围记录数和登记大小合计；明确它是 PG 元数据统计，不代表对象存储实时容量或账单，已删除记录不计入有效资产大小。
- 详情保持只读元数据，不提供后台预览、下载、批量删除或清理按钮。清理需要解决引用检查、对象删除与恢复策略，另行批准后实现。

### 视频导出 /admin/exports

- 扩展 platform_admin 到全平台编辑器导出任务元数据查询。列表按状态、任务 ID、项目 ID、发起人 ID、工程 ID、时间筛选并服务端分页。
- 展示任务/工程/项目/用户 ID、真实状态、创建/更新时间，以及从不可变快照提取并验证的分辨率、帧率、时长。不得返回完整工程快照、轨道、源文件引用、工程标题或媒体地址。
- 当前数据没有独立开始/完成时间和工程版本快照，不用 updated_at 伪造精确渲染耗时或使用当前工程版本冒充导出版本。缺失信息标明暂不可用。
- 错误只返回安全分类和说明，不直接暴露 FFmpeg 原始错误、文件路径或供应商信息。
- 新增 queued 导出任务取消；按 project_id + render_id 定位，与 Worker 领取使用相同行锁。Worker 已领取为 running 时返回 409，不杀正在执行的进程，不伪造终态。已 canceled 重放保持幂等。
- 取消和 editor 模块审计在同一 PG 事务提交，记录操作者、任务、前后状态、request_id 和时间；迁移增加审计表。不删除源引用、成片、工程或历史任务，不重新触发渲染。

### 接口和工程边界

- 复用现有平台管理员鉴权，每次从 PG 检查身份和账号状态；非管理员 404、未登录 401。写操作验证 Origin/CSRF；响应 no-store。
- 预计增加 GET /api/v1/admin/uploads、GET /api/v1/admin/assets 及对应带归属 ID 的详情；GET /api/v1/admin/editor-renders、GET /api/v1/admin/projects/{project_id}/editor-renders/{render_id}、POST 同路径 /cancel。
- uploads、generation、editor 分别负责自身查询与业务写入；必要聚合由 Application Service 调用公开用例完成。API 同步 OpenAPI 和前端生成类型。
- 保留现有项目/用户素材接口鉴权。管理员没有项目成员身份，也不因本提案获得私有媒体内容访问权限。
- UI 复用已有表格、分页、筛选、详情和确认交互；加载/空/失败状态明确，轮询仅页面可见时执行；缓存包含管理员身份和筛选。
- 不引入新依赖、新存储或新任务状态。

## Acceptance

- 普通用户、管理员撤权、跨归属详情定位、敏感字段排除和分页筛选测试。
- 上传与项目资产不混淆归属；有效大小合计排除 deleted；未知来源不伪称生成资源。
- queued 取消、重复取消、running 拒绝、Worker 领取竞态和审计失败回滚测试。
- 前端列表、筛选、详情、确认、刷新、错误反馈及窄屏检查。

## Consequences

用户确认后已更新架构管理查询例外，并实现接口、迁移与页面。资产页首版提供盘点和定位；不开放私有文件查看或删除。视频导出页提供任务监控与排队取消，不新增编辑器功能。
